# ovice — 3D AI 에이전트 오피스 (프로토타입)

AI 에이전트가 일하는 모습을 작은 3D 사무실의 캐릭터로 보여 주는 웹사이트입니다.

화면 아래 입력창에 조사할 내용을 적어 보내면, 캐릭터가 책상에서 일하는 과정을 말풍선과 진행 바로 보여 줍니다.
일이 끝나면 책상 앞으로 걸어 나와 주황색 폴더를 내밀고, 폴더를 누르면 결과 문서가 열립니다.
입력창을 10초 동안 쓰지 않으면 캐릭터는 은색 소파로 걸어가 앉아서 쉬고, 입력창을 누르거나 글자를 치면 책상으로 뛰어옵니다.
(휴대폰처럼 화면 폭이 좁으면 소파가 화면에 보이지 않으므로 책상에 그대로 있습니다.)
지난 작업은 오른쪽 아래 "작업 목록"에서 다시 열 수 있습니다. (작업 목록은 서버가 아니라 지금 쓰는 브라우저에만 저장됩니다.)

## 내 컴퓨터에서 실행하기

[Node.js](https://nodejs.org) 22(22.22 이상) 또는 24(24.15 이상)가 필요합니다.

```bash
npm install    # 처음 한 번만
npm run dev    # 개발 서버 실행
```

터미널에 나오는 주소(보통 `http://localhost:5173`)를 브라우저에서 엽니다.

## 테스트

```bash
npm test       # 단위 테스트 (약 30초)
npm run e2e    # 실제 브라우저로 전체 흐름 확인 (약 8분)
```

`npm run e2e`는 사이트를 빌드해서 띄운 다음, Chromium 브라우저로 "프롬프트 보내기 → 결과 받기 → 문서 열기" 같은 흐름을 직접 해 봅니다.
어느 컴퓨터에서나 같은 결과가 나오도록 3D 화면을 그래픽 카드 없이 그리기 때문에 시간이 좀 걸립니다.
(캐릭터가 소파까지 걸어갔다가 뛰어 돌아오는 흐름 하나가 그중 2분 반쯤을 씁니다.)
처음 한 번은 `npx playwright install chromium`으로 테스트용 브라우저를 설치해야 합니다.
이미 설치된 Chromium을 쓰려면 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`에 실행 파일 경로를 넣고 실행합니다.

## Vercel에 배포하기

1. [vercel.com](https://vercel.com)에 로그인하고 **Add New… → Project**를 누릅니다.
2. **Import Git Repository**에서 이 GitHub 저장소를 고릅니다.
3. **Framework Preset**이 **Vite**인지 확인합니다. (자동으로 잡힙니다. 빌드 명령과 출력 폴더는 저장소의 `vercel.json`에 적혀 있어 따로 입력할 것이 없습니다.)
4. **Deploy**를 누릅니다.

한 번 연결해 두면 그다음부터는 GitHub에 올릴(push) 때마다 자동으로 배포됩니다.
기본 브랜치에 올리면 실제 주소에, 다른 브랜치에 올리면 그 브랜치만의 미리보기 주소에 올라갑니다.

## 프로토타입 모드란

지금은 진짜 AI를 부르지 않습니다. 에이전트는 정해진 네 단계(요청 읽기 → 웹 검색 → 비교 → 리포트 작성)를 약 13초 동안 연출한 뒤,
"예시 결과물"이라고 표시된 견본 문서를 건넵니다. 문서 내용은 실제로 조사한 것이 아닙니다.

오른쪽 위 톱니바퀴(설정)에 있는 "실제" 모드는 아직 준비 중이라, 골라도 프로토타입 모드로 계속 동작합니다.

진짜 에이전트를 붙일 자리는 `src/agent/RealRunner.ts`입니다.
이 파일이 `src/agent/types.ts`에 정해 둔 약속(단계가 바뀔 때마다 알리고, 끝나면 결과 문서를 넘긴다)대로 동작하게 만들고,
`src/store/settings.ts`의 `AVAILABLE_MODES`에 `'real'`을 더하면 설정에서 "실제" 모드를 고를 수 있게 됩니다.
캐릭터는 손댈 필요가 없고, 화면에서는 고정된 문구 두 개만 바꾸면 됩니다: 결과 문서의 "예시 결과물" 배지(`src/ui/DocViewer.tsx`)와 설정의 "실제 (준비 중)" 이름(`src/ui/SettingsDialog.tsx`). AI 서비스의 API 키는 브라우저 코드에 넣지 말고 Vercel 서버 함수(`api/` 폴더)의 환경 변수로 보관하세요.

## 빨리 보기: `?fast=1`

주소 끝에 `?fast=1`을 붙이면(예: `http://localhost:5173/?fast=1`) 작업 단계가 20배 빨리 지나갑니다(약 13초 → 1초 이내).
시연하거나 테스트할 때 씁니다. 캐릭터가 걸어 나오는 속도는 그대로입니다.
